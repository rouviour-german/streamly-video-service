# Streamly Video Service

Streamly is a high-performance video streaming platform built with Next.js and Firebase. Inspired by premium streaming services, Streamly offers a seamless cinematic experience with a modern UI, real-time data fetching, and robust authentication.

## 🎬 Features

- **Personalized Streaming**: Browse a vast library of movies and TV shows, including trending content and originals.
- **Dynamic Previews**: Watch high-quality trailers directly via integrated video modals.
- **Secure Authentication**: User accounts and session management powered by Firebase Authentication.
- **Rich Media Details**: Comprehensive metadata for every title, including release dates, genres, and ratings.
- **High-Fidelity UI**: A stunning, responsive interface built with Tailwind CSS and Material UI.
- **State Management**: Efficient application state handling using Recoil.

## 🚀 Tech Stack

- **Frontend**: [Next.js](https://nextjs.org/), [React](https://reactjs.org/), [TypeScript](https://www.typescriptlang.org/)
- **UI/UX**: [Tailwind CSS](https://tailwindcss.com/), [Material UI](https://mui.com/), [Heroicons](https://heroicons.com/)
- **Backend**: [Firebase](https://firebase.google.com/) (Auth, Firestore)
- **State**: [Recoil](https://recoiljs.org/)
- **Media**: TMDB API integration for rich movie data.

## 📦 Getting Started

1. **Clone the Project**
   ```bash
   git clone https://github.com/rouviour-german/streamly-video-service
   cd streamly-video-service
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment**
   Rename `.env.example` to `.env.local` and add your Firebase credentials and TMDB API key.

4. **Launch Application**
   ```bash
   npm run dev
   ```
   Explore the platform at [http://localhost:3000](http://localhost:3000).
